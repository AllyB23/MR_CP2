PET SIMULATOR
Description : This is a simulator where you can simulate having a pet with game-like logic. You are able to feed your pet and take care of it as you would in real life. It is a text based game. YOu can keep track of the Charactersitics; Health, Hunger, Happiness, Enery, and the skills. 

This project is useful to simulate what it is like to have a pet and you can learn all of the responsibilities that it takes to have a pet.
